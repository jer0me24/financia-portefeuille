# Financia — portefeuille virtuel

Tableau de bord du portefeuille d'entraînement Financia : 50 000 € **fictifs** investis le 5 octobre 2026.
**Aucun argent réel n'est en jeu.**

Site : https://jer0me24.github.io/financia-portefeuille/

- Une « photo » du portefeuille est prise chaque soir de semaine vers 22h30 (heure de Paris), après la clôture américaine.
- Les jours passés ne sont jamais recalculés : la courbe montre l'historique réel.
- `data.json` contient les données affichées ; le reste est un site statique (HTML, CSS, JavaScript).
